What you are seeing. Drone / ISR video carries a hidden metadata track in KLV: where the aircraft is, where the sensor is pointed, how far away the ground it is looking at is. An FMV exploitation station overlays those numbers on the picture and drops the footprint on a map. This page does exactly that, but every number on it was produced by the misb Rust crate decoding real MISB ST 0601 KLV packets taken from the public ffmpeg KLV test videos (Day Flight.mpg and Night Flight IR.mpg, a sensor orbit over the Cold Lake range in Alberta). Sensor and frame-center positions, platform heading, slant range, field of view and the four footprint corners are the decoder's actual output.

What is honest to flag. The moving picture itself is a placeholder rendered from the metadata (a synthetic ground plane and reticle), not the original video frames, which are not shipped in this demo. The telemetry is real. And because it is real, it carries real defects: the same misb-check conformance tool flags every packet here, the whole file fails. Both samples send Target Width in 4 bytes where ST 0601 maps it onto 2, and several Night Flight packets fail SLANT-RANGE-MISMATCH (the Slant Range value disagrees with the distance between the decoded sensor and frame-center positions). Those findings, shown in the panel above, are the crate's own, not invented for the demo.
