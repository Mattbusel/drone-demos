Spec citations — ASTM F3411-22a / ASD-STAN / opendroneid

byte 0  Message header. High nibble = Message Type, low nibble = Protocol Version. Type 0x0 = Basic ID; version 2 = F3411-22a.
byte 1  ID / UA type. High nibble = ID Type, low nibble = UA Type. 1 = Serial Number (ANSI/CTA-2063-A); 2 = Helicopter / Multirotor.
bytes 2–21  UAS ID, 20 bytes, NUL-padded ASCII. CTA-2063-A serial = 4-char maker code + 1 length char + serial.
bytes 22–24  Reserved, 3 bytes, set to 0x00.
Bytes are not illustrative. They are the exact output of BasicId::new(IdType::SerialNumber, UaType::HelicopterOrMultirotor, "1596F35074529ABCDEFG").encode() from the remoteid crate, round-tripped back through Message::decode() to the fields shown.
